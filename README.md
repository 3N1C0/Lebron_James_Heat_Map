# LeBron James Shot Heat Map

A Jupyter notebook that plots LeBron James's shot locations on a basketball court and shows where his shots cluster.

## Files

| File | What it is |
|---|---|
| `Lebron Shot chart.ipynb` | The analysis and plots |
| `1_lebron_james_shot_chart_1_2023.csv` | Shot-location data |

## Skills demonstrated

- **Data loading and cleaning** with pandas
- **Custom plots:** drawing a basketball court from matplotlib arcs and patches
- **Density visualisation:** a heat map of shot frequency with seaborn
- **Presenting data:** colour scales and a clear, annotated chart

## Run it

```bash
pip install pandas numpy matplotlib seaborn jupyter
jupyter notebook "Lebron Shot chart.ipynb"
```
